# Full-text access

1. Check existing Zotero attachments and project archives. Prefer a lawful public copy from the publisher or a trusted repository. Record whether the copy is the version of record, an accepted manuscript, or a preprint.
2. When the user authorizes institutional retrieval, use their supported library resolver or normal publisher sign-in flow. The user completes any required authentication. Resume at the original article and check actual full-text access. Keep credentials, cookies, authorization headers, and signed resource URLs out of commands, logs, and manifests. Record the stable article URL.
3. Respect entitlement denials, verification requirements, and rate limits. If a download's outcome is unclear, inspect the authorized browser context and staging directory before retrying. If action is still required, record the article URL and the concrete blocker and continue other articles.
4. For a user-supplied batch, record each input path, size, and SHA-256 before copying. Match each file to a verified bibliographic record. If the file's identity is ambiguous, hold it for review. Use the same archive, attachment, and readback checks as for retrieved PDFs.

For scanned articles, check a rendered first page or OCR when text extraction returns nothing. A PDF signature alone does not establish readability, and readability does not establish bibliographic identity.
